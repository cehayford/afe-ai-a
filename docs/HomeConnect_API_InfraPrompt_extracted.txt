Authentication Requirements (from Auth Service + Quick Fixes)
Token type || JWT RS256 access token (15 min TTL) + refresh token (7 days)
Storage || Access token: memory only (never localStorage). Refresh token: httpOnly cookie.
Refresh flow || Silent refresh 60s before expiry using /auth/refresh endpoint
MFA gate || 6-digit TOTP or SMS OTP required for: password change, account deletion, device revocation
Role claim || JWT contains: role, country_id, currency_code, locale, verification_status
Interceptor || Every request adds Authorization: Bearer {token}. 401 ΓåÆ trigger silent refresh ΓåÆ retry once. 403 ΓåÆ show permission error, no retry.
Country routing || country_id from JWT injected as X-Country-ID header on every request

Role-Specific API Behaviour (Cross-cutting)
tenant || Standard endpoints. No owner_id / agent_id filter. GPS token required for review write and payment initiation.
landlord || All listing endpoints append owner_id={user.id}. Access to Compliance rules read. Escrow management endpoints.
agent || All listing endpoints append agent_id={user.id}. Access to Optimizer endpoints. Performance metrics. Availability management.
admin || No country_id filter enforced (can see all countries). Fraud score endpoints. KYC review endpoints. Compliance rules write. Dispute resolution endpoints.
country_id header || Injected from JWT on every request. Backend enforces RLS per country_id. Admin can override with X-Country-Override header.
